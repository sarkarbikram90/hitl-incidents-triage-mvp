Ajaia IT Ticketing System Design & Architecture (Assessment Submission)

This design addresses Ajaia’s rapid scaling challenges: onboarding 25+ team members, managing multiple AI systems & LLM access, safeguarding sensitive healthcare (HIPAA) & education (FERPA) data, and supporting multi-region remote teams.

1. Intake Channels (How Tickets are Submitted)

  • Slack / Teams Bot (#it-helpdesk): Conversational Slack bot parses requests using natural language NLP, extracts user role/region, and provides instant Tier-0 self-service answers or creates structured tickets.
  • Self-Service Employee Portal: Web form with role-based dynamic fields (e.g. LLM API Key Request, HIPAA Data Project Access, Hardware/MDM Support).
  • Email Forwarding (support@ajaia.io): Ingests external partner, vendor, or contractor inquiries into the unified queue.
  • Automated Telemetry & Compliance Webhooks: Automated triggers from AWS GuardDuty, Google Workspace DLP (HIPAA PHI alerts), and HRIS (BambooHR onboarding/offboarding sync).

2. Categorization, Prioritization & SLAs

Priority Definition & Example Scenario Target Response Target Resolution
P1 - Critical Active breach, HIPAA PHI leak, production AI API outage < 15 mins < 1 hour
P2 - High Blocked onboarding cohort, production LLM rate-limit spike < 1 hour < 4 hours
P3 - Medium Standard software license, single remote user VPN, FERPA review < 4 hours < 24 hours
P4 - Low General equipment request, documentation query, non-urgent < 8 hours < 72 hours

3. Routing & Assignment Rules

  • Tier 0 (AI Auto-Resolve): Standard password resets, approved SaaS access grants, and knowledge-base FAQs are resolved autonomously (41.8% deflection).
  • Clinical SecOps & Compliance Queue: Any ticket containing healthcare PHI, HIPAA tags, or education FERPA datasets routes to Compliance Specialists with mandatory human review.
  • Identity & Remote MDM Queue: Cohort onboarding batches auto-assigned based on timezone (US, EMEA, APAC) to regional IT leads.
  • AI Platform Engineering Queue: LLM rate limit adjustments, fine-tuning infrastructure requests, and API credential management.

4. How AI is Used to Reduce Workload (HITL Operations)

  • Intelligent Triage & Redaction: Automatically extracts symptoms, checks PII/PHI redaction, categorizes ticket, and sets priority in < 2 seconds.
  • Copilot Suggested Resolution: Pre-drafts a polite, complete response to the user and formulates ready-to-run automation scripts (Okta SCIM, Jamf MDM, AWS CLI).
  • Human-in-the-Loop Safeguard: IT Manager reviews the pre-drafted response and commands, tweaks if necessary, and executes with a single click.
